### Project Description
A voice and keyboard interaction experience that starts friendly but quickly descends into chaos. Users are encouraged to say "hello" or press random keys, only to be mocked and flooded with intrusive assets when they comply too enthusiastically.

### The Problem (that doesn't exist)
People take voice and keyboard interactions too seriously and expect predictable responses. Where's the fun in that?

### The Solution (that nobody asked for)
We created an experience that starts as a normal voice/keyboard interaction but gradually mocks users and floods their screen with chaotic elements when they follow instructions too obediently. It's the perfect way to keep users on their toes!

## Technical Details
### Technologies/Components Used
For Software:
- JavaScript (ES6+)
- Web Speech API
- HTML5 Audio
- CSS Animations
- Modern Web APIs

### Implementation
# Installation
No installation needed! Just open `index.html` in a modern browser.

# Run
1. Open `index.html` in Chrome/Firefox/Edge
2. Allow microphone permissions when prompted
3. Follow the voice or keyboard prompts
4. Enjoy the descent into chaos!
